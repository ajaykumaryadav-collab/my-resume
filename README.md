## ✨ Features

- **Direct Project Links**: Clear action buttons to visit each project's GitHub repository and live demos.
- **Split-Pane Layout**: Independent scrolling for the profile sidebar and main content area (Experience & Projects).
- **Dual Themes**: Polished Dark and Light modes with glassmorphism UI tokens and instant toggle.
- **Micro-Animations**: Fluid interactions powered by `framer-motion`.
- **Zero Jitter**: Layout locked to viewport height on desktop to prevent scroll-bounce and layout shifts.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS with modern tokens & custom scrollbars
- **Icons**: `react-icons` and `lucide-react`
- **Animations**: `framer-motion`

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ajaykumaryadav-collab/my-resume.git
   cd my-resume
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
