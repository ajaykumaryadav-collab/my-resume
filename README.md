# Arush Mehta - Interactive Resume

**[View Live Deployment on Vercel](https://arush-resume.vercel.app)**

A modern, interactive, split-pane digital resume built with **React**, **Vite**, and **TypeScript**. Designed as a standalone website separate from my main portfolio to provide a focused, premium reading experience for recruiters and engineering teams.

## Features

- **Split-Pane Layout**: Independent scrolling for the profile sidebar and the main content area (Experience & Projects).
- **Responsive Design**: Collapses into a clean, single-column view on mobile devices.
- **Premium Aesthetics**: Off-white/cream light theme with deep slate text, glassmorphism UI elements, and subtle micro-animations using `framer-motion`.
- **Zero Jitter**: Layout locked to viewport height on desktop to prevent scroll-bounce and layout shifts.

## Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS with modern variables & custom scrollbars
- **Icons**: `react-icons` and `lucide-react`
- **Animations**: `framer-motion`

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
